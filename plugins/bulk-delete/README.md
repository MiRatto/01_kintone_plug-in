# ミラっと_一括削除編

kintoneの一覧画面から、自分が作成したレコードを選んでまとめて削除するプラグインです。
利用者自身に、間違えて取り込んだデータなどを片付けてもらいたい場面を想定しています。

作者：ミラ／公開対象：version 8

## ダウンロード

このリポジトリの **Releases（リリース）** から、添付ファイル **`miratto-bulk-delete-v8.zip`** をダウンロードしてください。
解凍せず、そのままkintoneへ読み込みます。

GitHubが自動生成する「Source code (zip)」「Source code (tar.gz)」は、kintoneへ読み込むプラグインZIPではありません。

利用前に[利用条件・免責事項](TERMS.md)をご確認ください。

## できること

- 検索・絞り込み後の、現在の1ページから対象を選択する。
- 本人が作成し、本人に削除権限があるレコードだけを選択する。
- 1件ずつチェックする、または「全件にチェック」で選択可能な行をまとめて選ぶ。
- 一括でチェックした後、残したい行のチェックだけを外す。
- 対象のレコードID・件数・範囲を確認してから削除する。
- 削除直前に対象の作成者・削除権限・更新状況を再確認する。
- 削除成功後、完了画面の「OK」で一覧を更新する。

**削除したレコードは元に戻せません。** 必要なデータは削除前に保存してください。

## 対象と対応画面

- 対象は現在の1ページです。次ページや、検索・絞り込み結果の全件は含みません。
- 作成者はkintoneの「作成者」です。担当者・更新者・任意のユーザー選択フィールドではありません。
- 表示名ではなくユーザーコードで本人を判定します。管理者でも他人の作成分は選べません。
- 本人以外の作成分、削除権限のないもの、作成者や権限などを確認できないものは灰色で選択できません。
- PC版の表形式一覧に対応します。カレンダー形式・カスタマイズ形式・モバイル版は対象外です。
- 本プラグインの対象制限は本プラグインからの操作に適用されます。kintone自体のアクセス権設定を変更するものではありません。

## 導入

1. `miratto-bulk-delete-v8.zip`をダウンロードします。
2. kintoneシステム管理でプラグインを読み込み、利用するアプリへ追加します。
3. 利用者がアプリ・対象レコードを閲覧でき、削除権限を持っていることを確認します。
4. アプリの設定画面で「アプリを更新」を実行します。

追加の設定項目はありません。プラグイン設定画面には動作説明と外部ライブラリのライセンス全文があります。
導入には必要な管理権限が必要ですが、導入後に本プラグインで削除する利用者へアプリ管理権限を付ける必要はありません。
閲覧・削除権限を新しく付与する機能や、権限のないレコードを削除する機能ではありません。

開発版version 5・正式版version 6から更新する場合も、正式版ZIPをプラグインの更新として読み込んでください。同じプラグインIDを維持しています。

## 使い方

1. アプリの表形式一覧を開き、必要に応じて絞り込みやページ移動をします。
2. 「🗑️ 一括削除 🗑️」を押します。
3. 削除したいレコードにチェックを入れます。「全件にチェック」も使えます。
4. 「削除内容を確認する」を押し、対象ID・件数・操作範囲を確認します。
5. 元に戻せないことを確認するチェックを入れ、「N件を削除する」を押します。
6. 結果を確認します。すべて成功した場合は「OK」を押すと一覧を再読み込みします。

選択画面の項目はフィールドコードで表示します。長い内容はセル内、項目が多い場合は表全体を横にスクロールできます。

## 0件・キャンセル・エラー時

- 現在ページにレコードがなければ案内を表示し、削除しません。
- 選択0件では削除の確認へ進めません。
- 削除開始前は、選択画面・最終確認画面のどちらでもキャンセルできます。
- 操作中は開始ボタンを無効にし、二重起動を防ぎます。
- 確認中に対象の内容・作成者・権限や、表示ページ・検索条件などが変わった場合は停止します。
- 最大100件ずつ順番に処理します。エラー時は後続処理を停止し、自動再送はしません。
- 削除確認済みの件数・IDと、エラーが発生した送信対象IDを表示します。
- 通信が途切れた場合、最後の送信対象も削除済みの可能性があります。再実行前に一覧を更新して確認してください。
- エラー・0件・キャンセルでは一覧を自動更新しません。先に成功した削除を元に戻す機能はありません。

## 動作確認

開発版version 5で実機確認項目を一巡し、version 6では正式名称・設定画面の説明表示を整えました。version 7では薄い赤地のゴミ箱と薄いMRのアイコンへ変更しました。version 7までの削除処理とボタン配置のロジックはversion 5と同じです。

すべての環境や他のカスタマイズとの組み合わせでの動作を保証するものではありません。利用前にテスト用アプリで確認してください。
