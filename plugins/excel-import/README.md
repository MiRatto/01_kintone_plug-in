# ミラっとExcel_新規登録編

既存のExcel帳票を、取り込み用に毎回加工する手間を減らすためのkintoneプラグインです。

開始セル・読み込む右端の列・終了判定に使う列を設定し、選択したシートのデータを新規レコードとして登録します。
上部に見出しや装飾がある帳票も、データの開始位置を指定して読み込めます。

作者：ミラ／公開対象：version 17

## ダウンロード

このファイルが、kintoneへ読み込むための署名付きプラグインZIPです。

## できること

- 読み込みを始める列と行を指定する。
- 読み込む右端の列を指定する。
- 指定列の空欄を条件に、行の読み込みを終了する。
- Excelの列とkintoneのフィールドを、連番のフィールドコードで対応付ける。
- 取り込むシートを選び、開始行から3行のプレビューを確認する。
- データを100件ずつ、新規レコードとして登録する。
- 正常に登録できた場合、完了メッセージのOKを押して一覧を再読み込みする。

既存レコードの更新・削除は行いません。同じデータを再び取り込むと、新しいレコードとして重複登録される可能性があります。

## 対応ファイル・動作確認

- ファイル形式：`.xlsx`、`.xls`、`.xlsm`、`.xlsb`
- CSV・PDFなどは対象外です。拡張子だけをExcelのものへ変更したファイルも使用できません。
- パソコンのGoogle Chrome（Windows）で動作確認しています。
- マクロは実行しません。
- 250件の登録、100件単位の区切り、空欄判定、キャンセル、連打防止、重複・必須入力などによるエラー時の停止を確認しています。
- すべてのブラウザーやアプリ設定での動作を保証するものではありません。モバイル版kintoneは対象としていません。

## 導入

1. 配布用の`ミラっとExcel_新規登録編.zip`をダウンロードします。
2. kintoneシステム管理でプラグインを読み込み、利用するアプリへ追加します。
3. 以下のフィールドコードと読み込み設定を用意します。
4. プラグイン設定を保存し、アプリの設定画面で「アプリを更新」を実行します。

必要な権限や追加方法は、[kintone公式ヘルプ](https://jp.kintone.help/k/ja/app/plugin/settings/plugin)をご確認ください。

## 設定

| 項目 | 意味・選択範囲 |
|---|---|
| 開始セル・列 | 読み始める列。A〜AZ。 |
| 開始セル・行 | 読み始める行。1〜200。この数字は取り込み件数の上限ではありません。 |
| 読込終了列 | 読み込む右端の列。この列を含み、開始列と同じ列〜ZZ。 |
| 終了判定列 | この列が空欄になった行で終了。開始列より右側〜ZZ。読込範囲の外にも指定できます。 |
| 0・false・スペースを未記入として扱う | 初期状態はOFF。ONの場合、終了判定列の数値0・真偽値false・空白文字だけの値でも終了します。 |

終了条件に当たった行と、その後の行は登録しません。空欄がなければ、シートの使用範囲の末尾まで読み進めます。
未入力・空文字は空欄オプションのON/OFFにかかわらず終了対象です。

空欄オプションは**終了判定だけ**に使います。登録する値の0・false・スペースは変更しません。
文字列として入力された`0`・`false`は、数値0・真偽値falseとは別に扱います。

### フィールドコード

読み込み範囲内の各列について、対応するkintoneフィールドを用意します。
形式は`E_`＋Excelの列番号を3桁にした数字です。番号はExcelのA列から数えます。

| Excelの列 | フィールドコード |
|---|---|
| A | `E_001` |
| B | `E_002` |
| C | `E_003` |
| D | `E_004` |
| F | `E_006` |
| AZ | `E_052` |
| ZZ | `E_702` |

たとえば、開始セルB4・読込終了列D・終了判定列Fなら、B4〜D4を`E_002`〜`E_004`へ登録します。
F列は終了判定だけに使い、F列の値は登録しません。次の行も同じ対応で読み込みます。
非表示列も読み込み範囲に含まれます。範囲内の対応フィールドが不足している場合は、登録を始めずに停止します。

## 取り込み操作

1. アプリの一覧画面で「Excel一括取り込み」を押します。
2. Excelファイルを選びます。
3. シートを選び、設定範囲と3行のプレビューを確認します。
4. 「このシートで間違いありませんか？」を確認してOKを押します。
5. 結果を確認します。1件以上の登録が正常に完了した場合、OKで現在の一覧を再読み込みします。

0件・キャンセル・エラーの場合は自動で再読み込みしません。
一覧に絞り込みを設定している場合、新規レコードがその条件に合わず表示されないことがあります。

## 取り込み対象のフィールド

通常のフィールドのうち、次の種類を取込対象としています。

文字列（1行）、文字列（複数行）、リッチエディター、数値、日付、時刻、日時、リンク、ドロップダウン、ラジオボタン。

以下は対象外です。

- 計算フィールド、自動計算する文字列、ルックアップのコピー先。
- テーブル内のフィールド。
- チェックボックス、複数選択、ユーザー・組織・グループ選択、添付ファイルなど、配列形式の値が必要なフィールド。

対象の種類でも、必須入力・重複禁止・選択肢・値の形式・アクセス権など、アプリ側の条件を満たす必要があります。

### ルックアップ

キー項目へ値を渡す処理は行いますが、本版での動作確認は未実施です。
コピー元キーの重複禁止設定など、kintone REST APIの条件を満たす必要があります。
ルックアップのコピー先を、Excelの取り込み先として直接指定することはできません。

## 値の読み方・上限

- Excelの表示書式ではなく、保存された値を読み取ります。表示書式だけで付けた先頭ゼロなどは、その見た目のまま取り込む処理ではありません。
- 日付・時刻をkintone用の形式へ自動変換する機能はありません。登録先に合う形式の値が必要です。
- 数式は保存済みの計算結果を使い、再計算しません。計算結果がない数式やExcelのエラー値がある場合は停止します。
- 本プラグイン独自のファイルサイズ・件数の上限は設けていませんが、無制限の動作を保証するものではありません。端末・ブラウザー・kintoneの制限などに影響されます。
- 現時点では250件の取り込みを確認しています。大容量ファイルや大量データでの上限検証は未実施です。

## 途中でエラーになった場合

後続の登録を止め、画面に登録確認済みの件数と停止状況を表示します。詳細はブラウザーのコンソールへ記録します。
自動再送は行いません。

**先に成功した100件単位の登録は残ります。**
通信切断などで応答を確認できない場合、最後に送信した範囲も登録済みの可能性があります。
再実行する前に、一覧で登録状況を確認してください。
