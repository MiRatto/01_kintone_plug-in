# ミラっと_一覧保存

作者：ミラ／公開対象：version 13

列の並び・表示／非表示・幅・並び順・絞り込みを、同じアプリの同じアカウントで共通の3枠へ保存するkintoneプラグインです。
保存先はkintone内の専用アプリです。業務レコードや管理者が用意した共有一覧の定義を書き換える機能ではありません。

## ダウンロードと導入

このリポジトリのReleasesから **`miratto-personal-views-v13.zip`** をダウンロードし、解凍せずkintoneのプラグイン管理で読み込み、対象アプリへ追加します。
GitHubが自動生成する「Source code (zip)」「Source code (tar.gz)」は、kintoneへ読み込むプラグインZIPではありません。
利用前に[利用条件・免責事項](TERMS.md)をご確認ください。

旧版を導入済みの場合も、同じプラグインIDの更新として読み込めます。既存の保存用アプリや保存枠を作り直す必要はありません。

## 初期設定

1. 対象アプリのプラグイン設定画面を開きます。
2. 保存用アプリがある場合は、そのアプリIDを入力します。初めて使う場合は「保存用アプリを新しく作る」を押します。新規作成にはアプリ作成権限が必要です。
3. 保存用アプリのレコード権限が、作成者本人だけ閲覧・編集できる設定であることを確認し、確認欄にチェックを入れます。
4. 「確認して設定を保存」を押し、対象アプリの設定を反映します。

保存用アプリは保存キー・設定JSON・作成者を使います。通常利用者へアプリ管理権限を付与する必要はありません。アプリ管理者は権限設定を変更できます。
通常の保存・呼び出しはログインユーザーのセッション権限で動き、APIトークンを使いません。

## 使い方

1. 一覧上の「設定・保存」を押します。組込みの「すべて」一覧へ移動して設定画面が開きます。
2. 保存先1〜3と、ボタンに表示する名前を指定します。
3. 列名のドラッグまたは←・→で順序を調整し、表示のチェックと列幅を設定します。幅を空欄にすると自動です。
4. 並び順（ソート）と絞り込みを指定します。「すべての条件を満たす」はAND、「いずれかの条件を満たす」はORです。
5. 「保存して反映」を押します。設定した名前の呼び出しボタンから再び呼び出せます。

3枠は同じアプリ・同じアカウントで共通です。別の一覧で同じ番号へ保存すると、その枠を更新します。別アプリ・別アカウントでは分かれます。
他の一覧から呼び出した場合も「すべて」へ移動し、保存した条件・列・並び順を使います。
手動で列幅を調整したあと、再び枠を呼び出すと保存した幅へ戻ります。

### 詳細な条件式

詳細な条件式を直接入力した場合は、そのまま「保存して反映」を押してください。
「選択式で条件を作り直す」は、現在の詳細条件を消して選択式の設定へ戻す操作です。破棄確認で了承すると、入力していた詳細条件は消えます。

## 対応範囲

- パソコン版kintone用です。列の反映・設定は組込み「すべて」の表形式一覧で行います。
- カレンダー／カスタマイズ一覧からも呼び出せますが、それらの画面の列構造を直接変更する機能ではありません。
- 列は「すべて」に含まれるフィールドを基準にします。テーブル列等は対象外です。
- 「今日」「今月」「ログインユーザー」や、型に応じた空白／非空白の条件を指定できます。
- 通常の担当者フィールドとプロセス管理の作業者は別の項目です。作業者・ステータスは対象アプリのプロセス管理設定に従います。
- 行内編集の開始時は標準の列配置へ戻ります。編集後に保存枠を呼び出すと保存した配置へ戻せます。
- フィールドの削除・参照権限不足等で保存条件を解釈できない場合は、その条件を黙って取り除かずに停止します。
- kintoneの画面構造に依存する部分があり、すべての環境・他のカスタマイズとの組み合わせを保証するものではありません。

- 通信を一時停止した試験では、失敗の案内が表示されず、画面が切り替わらない挙動がありました。反応がない場合は通信状態を確認し、復旧後に開き直して保存内容を確認してください。画面が切り替わらないことだけで、保存完了を判断しないでください。
- 同じPCの別ブラウザーでの確認と、別PCでの確認は区別しています。別PCの確認は未実施です。
