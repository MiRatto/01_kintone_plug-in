## ダウンロード

各製品のReleaseページのAssetsから、下表の署名付きZIPをダウンロードしてください。ZIPは解凍せず、そのままkintoneへ読み込みます。
自動生成される「Source code (zip)」「Source code (tar.gz)」は、kintoneへ読み込むプラグインZIPではありません。
